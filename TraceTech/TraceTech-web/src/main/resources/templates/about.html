Sobre el proyecto

TraceTech

TraceTech es un gestor de incidencias desarrollado como proyecto académico, inspirado en flujos reales de soporte técnico y gestión de tickets.

Qué es TraceTech

La aplicación está pensada para simular un entorno de soporte donde distintos usuarios pueden crear, gestionar y seguir incidencias de forma organizada.

El proyecto ha servido para construir una aplicación web con una base sólida, aplicando arquitectura MVC, persistencia, validación, seguridad y vistas dinámicas.

Qué incluye

  • Gestión de tickets con estados OPEN, IN_PROGRESS y CLOSED
  • Asignación de tickets a técnicos
  • Comentarios por incidencia
  • Control de acceso por roles: ADMIN, TECH y CLIENT
  • Interfaz renderizada con Thymeleaf

Objetivo técnico

TraceTech nace con la idea de aplicar conceptos clave del desarrollo backend y full stack con Java: patrón MVC, JPA, validación de formularios, Spring Security y composición de vistas reutilizables.
